# 웹-일정관리 및 포모도로 타이머 (web-task-pomodoro)

웹 브라우저에서 바로 동작하는 직관적인 포모도로 타이머 및 할 일(To-Do) 관리 애플리케이션입니다.

## 프로젝트 소개
업무나 학습 중 집중력을 높이기 위한 포모도로 기법(25분 집중, 5분 휴식)과 할 일(To-Do) 관리를 회원가입이나 무거운 프로그램 설치 없이 웹 브라우저에서 가볍게 사용할 수 있도록 만든 오픈소스 프로젝트입니다.

## 현재까지 구현된 기능 (중간 점검 기준)
- [x] **포모도로 타이머**: 25분 집중 / 5분 휴식 카운트다운, 시작/일시정지/초기화 및 완료 알림
- [x] **할 일(To-Do) 관리**: 할 일 추가, 완료 체크(취소선), 삭제 기능
- [x] **로컬 스토리지 연동**: 새로고침하거나 브라우저를 다시 열어도 할 일 목록과 완료한 포모도로 횟수가 유지됨
- [ ] **주간 통계 차트 (향후 계획)**: Chart.js를 활용한 주간 집중 시간 시각화

## 실행 방법
별도의 서버 설치 없이 `index.html` 파일을 크롬(Chrome) 등 웹 브라우저로 열면 바로 실행됩니다.

## 기술 스택
- HTML5, CSS3, Vanilla JavaScript
- Web Local Storage API
- Chart.js (MIT License, 도입 예정)
